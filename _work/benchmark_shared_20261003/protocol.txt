Shared-representation comparison, user-requested revision 2026-10-03.
Eight blood-state/brain-state routes, seeds42/43/44. All fitted comparisons use the same frozen PeriScope blood encoder, protein head and brain decoder for each seed. Shared Ridge learns an OT barycentric map between these latent representations; conditional MLP and conditional ICNN use the same input features and frozen decoder. No-blood controls use training brain latent means/samples through that decoder. These controls do not use blood input by definition.
Raw predictions and validation-calibrated readouts are reported separately. Every method receives the same alpha grid[0,.25,.5,1] for a condition-independent pooled-training mean correction, chosen by validation mean MSE, and the same residual-scale grid[0,.25,.5,1], chosen by validation MMD. Reconstruction residuals come only from training brain expression through the shared brain encoder/decoder. Draws are centered exactly and paired across conditions. Thus gene-level disease contrasts do not change. Brain test donors and pig outcomes never select calibration parameters.
